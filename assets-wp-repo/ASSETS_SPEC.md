# WordPress.org アセット仕様書

これらのアセットファイルは、SVNリポジトリの `assets` ディレクトリにアップロードするためのものです。
**配布用プラグインのZipファイルには含めないでください。**

## 1. アイコン (Icons)
プラグイン検索結果やインストーラー画面で表示されます。

- **icon-128x128.png** (必須): 標準サイズ
- **icon-256x256.png** (推奨): 高解像度 (Retina) 画面用

**デザインのヒント:**
- 小さくても認識しやすい、シンプルなデザインにする。
- 可能な限り文字を含めない。
- 形式は SVG または PNG を使用する。

## 2. バナー (Banners)
プラグイン詳細ページ（公式ディレクトリ）のヘッダーとして大きく表示されます。

- **banner-772x250.png** (必須): 標準サイズ
- **banner-1544x500.png** (推奨): 高解像度画面用

**デザインのヒント:**
- モバイル表示でのトリミング（左右が見切れる等）を防ぐため、重要なテキストやロゴは中央寄りに配置する。
- ブランドカラーやプラグインの雰囲気に合った配色にする。

## 3. スクリーンショット (Screenshots)
詳細ページの「スクリーンショット」タブに表示されます。
ファイル名は `readme.txt` の `== Screenshots ==` セクションの番号と一致させる必要があります。

- **screenshot-1.png**: ウィジェット設定画面 (Widget Settings)
- **screenshot-2.png**: プラグイン設定画面 (Plugin Settings)
- **screenshot-3.png**: フロントエンド表示例 (Front-end Display)

**フォーマット:**
- PNG または JPG (PNG推奨)
- 推奨最大幅: 1200px (これより大きくても表示時に縮小されます)
